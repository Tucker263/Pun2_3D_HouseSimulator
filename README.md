# マルチユーザーVRシミュレーション基盤<br>（インテリア・エクステリアのシームレス設計）
> 室内と屋外を同時に、複数人でリアルタイム設計できるVRシミュレーション基盤

---


## 概要
本プロジェクトは、

**インテリア・エクステリア設計をシームレスに統合した  
マルチユーザーVRシミュレーションアプリケーション**です。

学部〜修士研究として、

- 企画
- アーキテクチャ設計
- 通信設計
- 状態管理設計
- 実装

を全て一人で担当しました。

※実際の研究用VRシステムを簡易3Dエミュレータとして再構築しています


---

## 背景
従来の設計支援システムの問題点

- 室内／屋外が分断
- 単一ユーザーのみに対応

| システム例 | インテリア | エクステリア | マルチユーザー対応 |
|------|------| ------|------|
| IKEA Place | ○ | × | × |
| メタバガーデン | × | ○ | × |
| Meta Horizon Workrooms | × | × | ○ |

→ 室内外の関係性を考慮した設計検討や、複数人でのリアルタイム協議が困難。


これらの課題を解決するために、

**室内外のシームレス統合 × リアルタイム協働設計**

を両立した基盤を設計・実装しました。

特に、顧客の内見支援、顧客やデザイナーの協働設計などに活用してもらいたいです。

---
## 主な機能

- ルーム内最大5人のリアルタイム同時接続（オフラインモード対応）
- 室内外のシームレス統合
- 3Dオブジェクトの生成・配置・回転・削除
- 内外装表面の材質変更（天井・内外壁・床・階段・屋根・ドア等）
- 室内照明・日照・街灯のリアルタイム変更
- マスタークライアントによるセーブ／ロード
- 途中参加・再入室時の最新状態同期
- ロコモーション操作（テレポート／スムーズ移動、空間ワープ）

## 設計上の特徴

### 1. リアルタイム同期設計
PUN2は基本的に PhotonViewのオーナーが状態を保持する分散モデルです。

- 動的オーナーシップ取得（操作時にRequestOwnership）
- 操作終了後はオーナーが状態保持
- RPCとOnPhotonSerializeViewの役割分離
- 差分同期設計
- 冗長送信抑制

を設計。

→ オーナー競合と状態不整合を抑制

---

### 2. 途中参加・再入室時の最新状態同期
入室ユーザーは**入室時にマスタークライアントから最新状態を取得する設計**としています。

1. 入室

2. JSONシリアライズ + gzip圧縮 + Base64エンコード

3. 初期状態に基づく差分バッチ処理

4. 新規ゲストのみ一括送信 

5. 新規ゲストローカル再構築

→ セッション継続性を担保

---

### 3. 通信最適化

- 微小差分の閾値制御
- RPC重複送信防止
- キューを用いたフレーム間の送信間隔制御
- gzip圧縮 + Base64エンコード

→ 帯域削減とリアルタイム性の両立

---

### 4. パフォーマンス設計

- オブジェクト探索のキャッシュ化（O(n) → O(1)）
- 定期キャッシュ削除でメモリ制御
- DFSを再帰ではなくスタック実装(スタックオーバーフローの回避)

→ 大量オブジェクト環境でも安定動作

## 苦労した課題

### 1. 分散Ownershipにおける競合問題
- 同時操作時の所有権奪取競合
- オーナー切替時の状態ロスト
- 途中退出時の孤立オブジェクト

→ 動的Ownership制御と状態保持ロジックで解決

---

### 2. 途中参加時の整合性崩壊問題
- 過去RPC履歴非保持問題
- 生成済みオブジェクトの不整合
- 状態再構築順序依存

→ Snapshot + 差分バッチ再構築方式で解決

---

### 3. 帯域制約とリアルタイム性の両立
- 全量同期による遅延
- 微小変化の無駄送信

→ 閾値制御 + キュー制御 + 圧縮で改善
