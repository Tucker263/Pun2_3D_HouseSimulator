# マルチユーザーVRシミュレーション基盤<br>（リアルタイム協働型VR設計システム）
> 室内と屋外を同時に、複数人でリアルタイム設計できるVRシミュレーション基盤

---
## 概要

**リアルタイム協働設計を可能とする  
マルチユーザーVRシミュレーション基盤**として、

既存コードのない状態からゼロベースで設計・実装。

学部〜修士研究として、研究テーマ（室内外シームレスVR）のもと
- 研究設計・企画具体化
- 分散同期設計
- 通信・状態同期設計
- 状態管理・永続化機構実装
- UX・操作設計
- 評価実験
- 英語論文執筆・国際発表

を一貫して担当。

英語論文執筆については助教の支援を受けつつ遂行。

研究成果は査読付き国際会議  
International Conference on Digital Image Processing and Pattern Recognition（DPPR2025） 
に採択・発表。

※3Dエミュレータとして基盤を再構築し、
実研究・協働設計の基盤動作を再現可能。

---

## 背景
従来の設計支援システムの問題点

- 室内／屋外が分断
- 単一ユーザーのみに対応

| システム例 | インテリア | エクステリア | マルチユーザー |
|------|------| ------|------|
| IKEA Place | ○ | × | × |
| メタバガーデン | × | ○ | × |
| VR設計一般 | ○/× | ×/○ | × |

→ 室内外の関係性を考慮した設計検討や、複数人でのリアルタイム協議が困難。


これらの課題を解決するために、

**室内外のシームレス統合 × リアルタイム協働設計**

を両立したシステムを設計・実装。

特に、
- 内見支援
- デザイナー協働
- 空間シミュレーション

への応用を想定。

## 主な機能（基盤視点）

- ルーム内最大5ユーザー同時接続（オフラインモード対応）
- 分散リアルタイム同期
- 室内外のシームレス統合
- 3Dオブジェクト操作(生成・配置・回転・削除)
- 内外装表面の材質変更（天井・内外壁・床・階段・屋根・ドア等）
- 室内照明・日照・街灯のリアルタイム変更
- セッション保存／復元
- 途中参加時の最新状態同期
- ロコモーション操作（テレポート／スムーズ移動、空間ワープ）

## 分散・同期設計（基盤の特徴）

### 1. リアルタイム同期設計

- 動的オーナーシップ取得（操作時にRequestOwnership）
- 操作終了後の状態保持
- RPCとOnPhotonSerializeViewの役割分離
- 差分同期設計
- 冗長送信抑制

→ オーナー競合と状態不整合を抑制

---

### 2. 途中参加・再入室時の最新状態同期
入室ユーザーはマスタークライアントから最新スナップショットを取得：

1. 入室
2. JSONシリアライズ
3. gzip圧縮 + Base64エンコード
4. 初期状態に基づく差分バッチ処理
5. ローカル再構築

→ セッション継続性を担保

---

### 3. 通信最適化

- 微小差分の閾値制御
- RPC重複送信防止
- フレーム間送信キュー制御
- gzip圧縮 + Base64エンコードによる帯域削減

→ 帯域削減とリアルタイム性の両立

---

### 4. パフォーマンス設計

- オブジェクト探索のキャッシュ化（O(n) → O(1)）
- 定期キャッシュ削除でメモリ制御
- DFSのスタック実装(再帰によるスタックオーバーフロー回避)
- gzip圧縮 + Base64エンコードによるセーブ容量削減

→ 大量オブジェクト環境でも安定動作

## 苦労した課題

### 1. 分散Ownershipにおける競合問題
- 同時操作時の所有権奪取競合
- オーナー切替時の状態ロスト
- 途中退出時の孤立オブジェクト

→ 動的Ownership制御と状態保持ロジックで解決

---

### 2. 途中参加時の整合性崩壊問題
- 過去RPC履歴非保持問題
- 生成済みオブジェクトの不整合
- 状態再構築順序依存

→ Snapshot + 差分バッチ再構築方式で解決

---

### 3. 帯域制約とリアルタイム性の両立
- 全量同期による遅延
- 微小変化の無駄送信

→ 閾値制御 + キュー制御 + 圧縮で改善
