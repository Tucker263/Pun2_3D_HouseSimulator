# Pun2_3D_HouseSimulator
## 概要
大学院修士「VRを用いたインテリアとエクステリアのシームレスなシミュレーションシステムの開発」


大学院の研究で、VRに機能を導入するために、開発したUnityの3Dエミュレータ <br>
※実際の研究で開発したVRのシステムは別にあります

## 実装した機能
・ 複数のユーザー間の通信 <br>
・ FPS視点とTPS視点の切り替え <br>
・ 移動と視点の回転、ワープ <br>
・ 照明のオンオフ、明るさの変化、種類の切り替え <br>
・ 時間帯に応じた太陽と街灯のシミュレーション <br>
・ 3Dデータのセーブとロード <br>
・ 家具などの3Dオブジェクトの生成と配置、回転、破棄 <br>
・ 外装(屋根,外壁)、部屋ごとの内装(天井,内壁,床)、ドアの材質変更 <br>
・ ドアと窓の開閉 <br>
・ 直観的な操作が可能なUI <br>

## 実装のポイント
### クラス設計とデータ構造
・ クラス単一責任の法則を遵守 <br>
・ UI層とロジック層の分離 <br>
・ 可読性の向上 <br>
・ デザインパターン(ファクトリーバターン)の使用 <br>
・ Scriptableオブジェクトの使用 <br>
・ セーブロード機能、同期機能において、継承を使用してコード量を削減


### 通信の同期,容量の削減
・ 新規ユーザーの参加時は、差分バッチ、gzip+Base64の圧縮、キューによる送信間隔の制御 <br>
・ RPC通信において、数値に閾値を設け、小さい差分は無視し、送信を制御
・ RPC通信において、連打による重複送信の防止


### 計算量の削減
・ 大量のオブジェクトの探索でキャッシュを利用し、o(n)から2回目以降はO(1)に削減 <br>
・ 定期的にキャッシュを削除することで、メモリの使用量も削減 <br>
・ 家オブジェクトのDFS探索で、再帰ではなくスタックを使用し、スタックオーバーフローも回避
