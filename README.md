# Pun2_3D_HouseSimulator
## 概要
大学院修士「VRを用いたインテリアとエクステリアのシームレスなシミュレーションシステムの開発」


大学院の研究で、VRに機能を導入するために、開発したUnityの3Dエミュレータです

## 実装した機能
・ 複数のユーザー間の通信 <br>
・ FPS視点とTPS視点の切り替え <br>
・ 移動と視点の回転 <br>
・ 照明のシミュレーション <br>
・ 時間帯に応じた日照と街灯のシミュレーション <br>
・ ドアと窓の開閉 <br>
・ 3Dデータのセーブとロード <br>
・ 家具などの3Dオブジェクトの生成と配置、回転、破棄 <br>
・ 外装(屋根,外壁)、部屋ごとの内装(天井,内壁,床)の材質変更 <br>
・ 直観的な操作が可能なUI <br>
